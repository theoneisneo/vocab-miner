# 跟唱網頁的資料檔格式（songs.json）

跟唱網頁（`web/`）讀取的資料檔。一般用 `uv run vm web` 產生即可；這份說明給想**自己寫程式產生**資料檔的人。

- 編碼 UTF-8 的 JSON。
- 網頁匯入時會檢查格式，不符時會列出哪裡有問題。
- 標示「選填」的欄位可以省略，網頁會用較簡單的方式顯示。

## 最小可用的例子

```json
{
  "format": "vocab-miner-web",
  "version": 1,
  "title": "我的歌",
  "words": [
    {"key": "雨\tあめ", "lemma": "雨", "reading": "あめ", "romaji": "ame", "zh": "雨"}
  ],
  "docs": [
    {
      "id": "songs/rain",
      "title": "雨の歌",
      "media": {"kind": "youtube", "uri": "影片ID"},
      "lines": [
        {"start": 12.5, "end": 15.0,
         "seg": [["雨", "あめ", 0], ["が降る", null, null]],
         "romaji": "ame ga furu",
         "tr": "下雨了"}
      ]
    }
  ]
}
```

## 頂層

| 欄位 | 型別 | 說明 |
|---|---|---|
| `format` | 字串 | 固定為 `"vocab-miner-web"` |
| `version` | 數字 | 固定為 `1` |
| `title` | 字串，選填 | 資料檔的名稱，顯示在首頁。**同名的檔案再次匯入會更新而不是新增**；省略時用檔名 |
| `lang` | 字串，選填 | 原文語言（BCP-47，例如 `ja`） |
| `generated` | 字串，選填 | 產生時間（ISO 8601），顯示在首頁 |
| `words` | 陣列 | 詞彙清單，見下方。句子裡用**陣列索引**（從 0 開始）指到這裡的詞 |
| `docs` | 陣列 | 歌曲（或場景、章節），至少一個 |

## words：詞彙

| 欄位 | 型別 | 說明 |
|---|---|---|
| `key` | 字串 | 詞的唯一識別（vocab-miner 用「原形\t讀音」）。**「已學會」的紀錄依 key 保存**，不同資料檔裡 key 相同的詞視為同一個詞 |
| `lemma` | 字串 | 原形，顯示在詞卡上 |
| `reading` | 字串，選填 | 讀音（日文為平假名） |
| `romaji` | 字串，選填 | 拼音 |
| `pos` | 字串，選填 | 詞性名稱，顯示用（例如「動詞」） |
| `upos` | 字串，選填 | Universal POS（`NOUN`、`VERB`、`ADJ`、`ADP`、`PART`、`SCONJ`、`AUX`…），「結構」上色用 |
| `short` | 字串，選填 | 很短的意思（建議 6 個字以內），顯示在「逐詞」模式的每個詞底下。省略時取 `zh` 的第一個意思 |
| `zh` | 字串，選填 | 中文釋義 |
| `en` | 字串，選填 | 英文釋義 |
| `ff` | 字串，選填 | 同形異義警告（漢字和中文相同但意思不同時的說明） |
| `grammar` | 布林，選填 | 是否為文法詞（助詞、助動詞）；文法詞不算進「已懂比例」和生詞數 |
| `rank`、`count`、`docFreq` | 數字，選填 | 學習順序、總次數、出現在幾首，顯示在詞卡上 |
| `status` | 字串，選填 | `known` 表示一開始就算已學會（使用者在網頁上的標記會覆蓋它） |

## docs：歌曲

| 欄位 | 型別 | 說明 |
|---|---|---|
| `id` | 字串 | 在檔案內唯一。手機上選的本機影音檔依這個 id 記住 |
| `title` | 字串，選填 | 歌名 |
| `media` | 物件或 null，選填 | `{"kind": "youtube", "uri": "影片ID"}` 時顯示 YouTube 播放器。沒有的話，使用者仍可在網頁上選手機裡的影音檔來播放 |
| `noStats` | 布林，選填 | 例如同一首歌的另一個版本：列在首頁的「其他版本」 |
| `lines` | 陣列 | 句子，依順序 |

## lines：句子

| 欄位 | 型別 | 說明 |
|---|---|---|
| `start`、`end` | 數字或 null，選填 | 這句在影音裡的開始、結束秒數。有 `start` 才能點句子播放 |
| `seg` | 陣列 | 句子切成的片段，見下方。所有片段的文字接起來就是整句 |
| `romaji` | 字串，選填 | 整句拼音 |
| `wr` | 字串陣列，選填 | 每個 token 的拼音（索引對應 `seg` 的第 4 個值），「逐詞」模式顯示在每個詞底下 |
| `tr` | 字串，選填 | 翻譯 |
| `ex` | 字串，選填 | 這句的解說（為什麼這樣翻），在工具列「解說」打開時顯示 |

### seg 的每一段

`[文字, 讀音, 詞索引, token 索引]`

- **文字**：這一段的原文。
- **讀音**：要標在這段文字上方的讀音（注音假名），不需要時填 `null`。
  一個詞可以拆成多段，只在漢字上標讀音，例如「食べる」寫成 `["食", "た", 3, 0], ["べる", null, 3, 0]`。
- **詞索引**：指到 `words` 的索引，點這段文字會打開那個詞的詞卡；標點、不在詞彙表裡的部分填 `null`。
- **token 索引**（選填）：同一個詞的多個片段填相同的值，網頁會把它們當成一個單位（逐詞模式、點擊範圍）。
  省略時，連續且詞索引相同的片段會合併。

## 版本

格式有不相容的變更時，`version` 會加一，網頁會拒絕匯入版本不符的檔案並說明原因。新增選填欄位不會改變版本號。
