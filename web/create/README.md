# 選用功能：在網頁裡建立歌曲

不需要電腦或命令列，在跟唱網頁裡直接建立一首歌：

1. 貼上歌詞（一行一句；已有時間軸的 LRC 也可以）和 YouTube 連結。
2. 邊聽邊點「這一句開始了」標時間，再逐句用 ±0.1 秒微調。
3. （可略過）按「問 AI 翻譯整首」，把 AI 的翻譯貼回來。
4. 在瀏覽器裡分詞（日文用 [kuromoji.js](https://github.com/takuyaa/kuromoji.js)，第一次使用時從 CDN 下載約 12 MB），
   產生注音、拼音、逐詞和結構上色，存成一份叫「我建立的歌曲」的資料檔。和其他資料檔裡相同的詞會沿用它們的釋義和「已學會」紀錄。

## 為什麼獨立成一個資料夾

這是目前想到的較好做法，實際使用後可能會大改或拿掉，所以刻意和主程式分開：

- 所有程式在這個資料夾（`create.js`、`create.css`），只在使用者打開這個功能時才載入。
- 主程式 `web/app.js` 只透過 `featureApi()` 這個介面物件和它溝通。
- 建立出來的歌曲用一般的資料檔格式（[docs/web-data-format.md](../../docs/web-data-format.md)），所以拿掉這個功能後，已經建立的歌曲仍然可以照常使用。

## 怎麼關閉或移除

- **關閉**：把 `web/app.js` 裡的 `const FEATURES = { create: true };` 改成 `false`。
- **移除**：關閉之外，再刪掉這個資料夾，以及 `web/app.js` 裡標示 `optional feature` 的幾行
  （`FEATURES`、`featureApi`、`openFeature`、選單項目和首頁的兩個按鈕）。

## 目前的限制

- 只支援日文。其他語言需要在 `LANGS` 加上對應的瀏覽器分詞器。
- 新詞沒有中文釋義（除非其他資料檔裡已有同一個詞）；可以用詞卡的「問 AI 這個詞」。
- 學習順序只沿用其他資料檔的排名，不會為新歌重新計算。
- 分詞器第一次需要網路；建立好的歌曲之後離線也能看。
- 建立後還不能在網頁裡修改；要改就刪掉「我建立的歌曲」重新建立，或在電腦上改資料檔。
