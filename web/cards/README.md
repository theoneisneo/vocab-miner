# 選用功能：單字卡與測驗

日文資料檔在首頁多一個「單字卡」分頁，用這份資料檔歌詞裡出現的所有詞（不分歌曲；文法詞和英文詞除外）：

- **單字卡**：漢字（有才顯示）、假名、拼音、🔊 朗讀、中文意思；可依學習順序或隨機瀏覽，按「同字首」「同字尾」看相關的詞。
  下面是歌詞裡的例句（逐詞顯示意思、整句翻譯；先 3 句，可展開全部），點歌名從那句開始播放。測驗作答後也會顯示。
- **測驗**：每次 20 題，看單字選出中文意思（5 選 1）。錯的選項優先從同字首、同字尾的詞裡抽，再來是同詞性的詞。
  出題方式：高頻詞（前 60 個還沒學會的詞裡抽）、隨機、依字數（假名數；太少的字數併到相鄰的組）、答錯複習。
- **紀錄**：每次測驗的答對率和累積答對率；答錯的詞進「答錯複習」，連續答對 2 次才移出。
  紀錄存在這個裝置上，只有按「重計測驗結果」才會清除。

「同字首／同字尾」：有漢字的詞比第一個／最後一個漢字（送假名不算，歩く 看 歩）；只有假名的詞比開頭／結尾兩個假名
（片假名當平假名比）。

電腦上：測驗用 1–5 鍵作答、Enter 下一題；單字卡用 ← → 換卡、Esc 關閉。

## 為什麼獨立成一個資料夾

和 `web/create/` 一樣：程式都在這個資料夾，打開分頁時才載入，主程式只透過 `featureApi()` 和它溝通。
關閉：把 `web/app.js` 的 `FEATURES.cards` 設成 `false`；移除：再刪掉這個資料夾。
