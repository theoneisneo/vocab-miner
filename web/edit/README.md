# 選用功能：編輯一句歌詞

在跟唱網頁的「編輯歌詞」模式下，每一句都有「✎ 編輯」，打開下方的編輯面板：

- **逐詞顯示**：日文和拼音上下對齊，一個詞一格。點一個詞可以：
  - **刪除這個詞**：日文和拼音一起刪，不會出現只刪一邊的情況。
  - **改讀音**：歌詞特殊讀法（例如「本気」唱成「マジ」）時，改這個詞的假名，拼音會跟著更新。
  - **從這裡拆成新的一句**：在這個詞前面拆開。新句子的開始時間依字數比例估算，翻譯留在第一句。
- **改字**：改整句的日文後按「重新分詞」，在瀏覽器裡重新分詞（[kuromoji.js](https://github.com/takuyaa/kuromoji.js)，
  第一次使用時下載約 12 MB），讀音和拼音重新產生。
- **翻譯**：自由修改，不和日文連動。
- **時間**：開始和結束各有 ±0.1 秒和「設成現在」（用影片目前播放的位置）。
- **和下一句合併**、**刪除這句**、**復原本句**（回到打開這句時的樣子）。

修改會立刻存在這台裝置上（IndexedDB 的 `lineEdits`），重新整理網頁也還在；資料檔重新產生後，只要原本的句子沒變，修改照樣套用（變了會在編輯列提醒）。
「匯出資料檔」會把修改寫進資料檔，可以匯入其他裝置。

## 檔案

- `edit.js`、`edit.css`：編輯面板，打開時才載入。和主程式只透過 `openLineEditor(api)` 收到的 `api` 物件溝通。
- 日文分詞、讀音、拼音的共用程式在 `../lib/ja.js`（「建立一首歌」也用它）。
- 存放修改、把修改套到歌曲上、匯出，在主程式 `web/app.js` 的「edited lines」一節。

## 移除

刪掉這個資料夾，以及 `web/app.js` 裡的 `openLineEditor` 和「✎ 編輯」按鈕。已經做的修改仍會照常顯示（由主程式套用）。
